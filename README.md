# AI短剧分镜与视频提示词 Skill

把锁定剧本整理成视频生成模型能明确执行的声画提示词：先设计完整场景，再分成Clip，保留动作、听话反应、情绪、空间、光线和声音承接。

**v0.1.0 · 实验版 · GPL-3.0-only**

真人短剧和动漫表现均按项目要求选择。工具不绑定某个模型，不自带API账号、视频生成服务或素材。

## 安装与开始

将 `skills/ai-manju-director-scene-first` 整个目录复制到智能体支持的技能目录，保留 `references`、`scripts`、`LICENSE` 和 `NOTICE`。

Codex用户可放到配置的技能目录（通常为 `$CODEX_HOME/skills`；未设置时通常为 `~/.codex/skills`）。目录名和Skill名称保持 `ai-manju-director-scene-first`。

提供锁定剧本、需要制作的范围、风格、角色/场景素材与生成条件，然后请求：

```text
使用 $ai-manju-director-scene-first 制作这场戏。
先保存完整整场声画稿和制作记录，再读取它们整理Clip。
执行两轮整体复核，保留逐镜正文证据及各阶段版本。
风格：真人短剧。素材尚未提供，角色栏只写名字。
默认每Clip 4—15秒，只写Clip总估时。
剧本见我提供的文件。
```

一个可直接试用的自编小输入见 [examples/locked-scene.md](examples/locked-scene.md)。这是使用演示，尚未生成视频，不是效果合格案例。

纯API环境没有文件读取能力时，调用方要将本次所需的Skill与参考正文实际送入模型；上传一个目录或只发送入口名称不会自动读取参考文件。按阶段保存整场稿、制作记录、Clip稿和两轮修订版本。

## 工作流与交付

1. 完整阅读制作范围，明确事件、台词、知情顺序、固定空间及实际素材。
2. 完成整场连续演出和真实镜头稿，登记共用估时，保存制作记录。
3. 读取整场稿，按自然话语或动作节点整理Clip；每Clip保留起态、画质氛围、站位、三链、声音、镜头正文和末态。
4. 两轮自主整体复核，修正对应正文和状态，保留证据及版本。

每Clip默认4—15秒；用户指定其他受支持范围时采用本次要求。切镜本身不增加演出时间。画幅用于项目构图，分辨率放在视频提交配置，正文不强制480p或横屏。

入口：[SKILL.md](skills/ai-manju-director-scene-first/SKILL.md)。输出字段与模板：[output-format.md](skills/ai-manju-director-scene-first/references/output-format.md)。

## 辅助检查

需要Python 3，仅使用标准库：

```bash
python skills/ai-manju-director-scene-first/scripts/check_delivery.py clips.md --source scene.md --out audit.json
```

此脚本只检查可识别字段、Clip总时长及已识别台词的一致性。JSON中的 `structural_checks_passed` 不代表因果、人物、机位、演出、口型或视频接缝正确；当前镜头标题识别也有格式边界。请读取输出中的limitations和review_warnings。

## 已知问题与验证范围

本版以本地候选03为公开基线，仅调整发布身份、资料说明、原文摘录和许可包装；核心制作规则沿用该基线，没有采用候选04新增展开段。

2026-10-06本地对照涉及坐起取手机、稿纸交接与长对白三个小段。两个制作子智能体分别生成两版首稿，一个匿名审阅；整场到Clip的逐镜正文均保留。候选04没有显示整体优势，所以沿用03。两版仍有部分机位与关键动作可见性风险；候选04另有停接话顺序与链条不一致的例子。

该轮只执行整场与Clip两个首稿阶段，没有执行默认两轮复核或生成视频。它不证明整集持续输出、跨模型稳定性或实际视频效果。公开包装后的完整流程尚未重复测试。详细边界见 [docs/verification.md](docs/verification.md)。
