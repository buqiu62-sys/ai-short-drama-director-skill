# 逐Clip文本交付

用于用户沿用的“场 → Clip → 真实镜头 → Clip结束状态”Markdown视频稿。时间与分组按[timing.md](timing.md)，边界状态按[continuity.md](continuity.md)，对白轨写法按[dialogue.md](dialogue.md)。本版的可用交付路径是下述文本格式。

## 组织方式

本格式用于完整整场声画稿之后的整理阶段。沿用已经成立的真实镜头、演出顺序、切点和声音词段，必要修订连同整场稿保存。三链过程说明与边界状态从镜头提取，与逐镜演出一致，不作为另一套独立导演稿。

每个Clip能够独立用于生成，展开必要场景、素材、状态和照明，不以“同上”省略。人物栏只列出场名字和实际素材引用，资产缺口按look-assets.md处理。开场动态交给“上一Clip状态”，空间关系交给“站位”，当前画风与光源基底交给“画质氛围”。机位写摄影机在哪里、朝哪里看及必要高度。焦距在对取景有实际作用或项目要求时补入镜头行，使用毫米数时按全画幅等效记录；具体可见范围和画面变化正常展开。

画幅由项目设置统一提供并用于构图；分辨率留在生成提交设置。逐Clip正文不重复分辨率、画幅等技术参数，“画质氛围”只写画风、视觉质感、色彩及当前光源关系。

面向视频生成模型写执行内容。整理时读取[画面展开](visual-description.md)，按其中的硬性完成条件把动作路径、可见身体配合、具体触发与反应、场景层次、接触反馈、本镜受光和声音进度完整落到对应镜头。整场稿已缺少过程时回到该镜补齐并同步保存，不能照搬遗漏；已展开的内容整理时保留，不能为缩短文字删成情绪标签或动作结果。景别、机位、运镜名称帮助定位，人物心理与拍法意图落实为当前取景能辨认的变化，选择依据另存制作记录。

每个Clip在标题中填写总时长，内部按镜号排列，不标逐镜秒数或起止时间。每个镜号对应一个真实镜头或其连续部分，同场镜号连续。硬切新起镜号；同镜跨Clip沿用镜号并标“续”。正文交代切换发生在什么话语、动作或反应节点，并承接正在进行的声音和行动。

本Clip过程单列在起始资料之后、镜头之前，描述全段演变：

- 动作链：从本Clip实际起态连写谁对谁或什么怎样行动，保留使动作成立的准备、支撑或两手分工、接触与转移、完成或未完状态。用人物名字和明确对象串起过程；先后与并行关系可辨，准备已在前段完成就继承，不重复起做。人物对另一人的行动及其结果也属于行动。物件怎样受力、被托稳和归属转移放在此处。
- 反应链：沿人物实际接收的信息及相互影响连写“具体话意或事件触发谁—其正在进行的行为、注视、表情或发声怎样回应—这使随后的互动怎样继续，或停在哪个状态”。回应在话中还是结果之后须清楚；保持沉默或原态也可成立，但交代其接收及保持的实际表现。物件支撑不能占据整条反应链；它只有被人物感知并影响回应时才作为触发重提。无新互动时写已有接收或态度的维持，不编追问、争吵或旁人反应。
- 情绪变化：按本段关键人物写清当下外显态度怎样保持、受触动、泄露或掩饰，采用镜头里已选的眼神、嘴角、肩背、手部、呼吸或语声变化作证据。人物内心认识与外显表现分别归属，依据其当时知情；同一人可始终克制，不强迫每人经历转折。“平静”“震惊”“自然转念”等说明须有具体表现，禁止事项不代替正在发生的演出。
- 声音：整体声场、动作同步声的进出、连续对白跨镜关系及段末进度。

三个链是同一演出的三种过程说明，共享事实、触发与时序，每条都应能独立读通自己的关系。用完整句保留核心准备、过程与落点；镜号可用于定位，不代替主语、对象和过程，也不用只列“拿出—放入—合上”概括尚需执行的关系。不规定字数，说明足够就结束，不逐镜复制全部画面、灯光或对白原文。

动作链重在行动的实现，反应链重在信息接收及相互影响，情绪变化重在态度怎样显露。同一触发可从不同关系重提，后文须增加相应信息，不能三遍照抄同一动作顺序。三链的每个核心变化都须有对应镜头正文；逐镜仍完整写出实际过程、可见范围、声光及声音进度，不能因为开头已经写过而删薄。若三链展开时发现正文缺项，回到同一演出补齐并同步整场稿，不只在开头编出过程。动作跨镜或跨Clip时保留未完相位，接触、持有权和结果有连续依据。

## 模板

```text
场【场号】（场名）｜场景／内外／时间

Clip01｜镜【起始镜号】-【末镜号】｜【总时长】秒（估时）
角色：【本Clip出场名字与真实绑定的素材引用】
场景：【场景结构、必要道具与真实附件编号】
上一Clip状态：【本段0秒继承的动作相位、姿态、视线、手与物件关系及必要残留；首段写初态】
画质氛围：【当前媒介与具体成像质感、主辅色与亮暗层次、实际光源及作用范围、当前主体与物件的受光和暗面来源、可见材质及空间/环境状态；按look-assets.md完成，不用风格套话代替现场】
站位：【本段0秒人物与关键物件相对固定参照的位置、站坐高度与朝向、具体相互关系和实施距离、有关遮挡及通路，包含影响本段的镜外位置；按continuity.md完成，摄影机留在逐镜机位】

本Clip过程（全段演变，非首帧状态）：
动作链：【】
反应链：【】
情绪变化：【】
声音：【总体声场、连续声轨的镜间关系与段末进度；台词原文写在镜头中】

画面内容：
镜【编号】｜景别：【】·机位：【】
运镜：【已选固定观看或连续移动路径；续镜写承接进度】
画面：【按画面展开硬性完成条件，写清主体与对象的起态、本镜实际动作相位与落点、接触及持物转移、可见身体配合、具体触发和实际回应、场景层次与反馈、本镜受光。按真实先后或并行连写；发言者、画内/画外及原文词段、接触声与环境声对应同一次演出。取景外的过程交代承接依据，不写成画内可见】

【按实际切镜继续】

Clip结束状态：【最后实际达到的状态、尚在进行的动作、声音及对白进度】
```

执行稿只包含生成所需内容，制作记录、备选讨论和复核报告另存，不在文末追加关键帧区。保留原有文本标签；网站是否完整保留过程区，需要实际适配验证，文本规范本身不代表已经接入。
