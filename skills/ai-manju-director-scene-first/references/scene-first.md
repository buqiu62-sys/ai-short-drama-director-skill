# 整场声画稿与 Clip 整理

## 先把整场真正写出来

整场稿是已选拍法的完整声画执行稿，覆盖委托的场景初态至结果；制作记录中的提纲不能代替它。整集先理解完整内容，再逐场制作，共享已确定的事实和前后状态。

完整阅读本场及必要前后文后，先确定人物目的、站位、知情与本场结果，展开他们怎样通过发言和行动相互影响。按[时间与生产](timing.md)保存连续发言和动作的共用估时依据，再依据[对白与声音](dialogue.md)安排话语进度与当场接收，按[分镜参考](shot-patterns.md)比较这个演出如何被观看，再用[景别](shot-choice.md)和[运镜](camera-movement.md)落实观看范围与路径。演出与观看统一写进整场稿，不另增一套过程表。短剧的推进来自声画中持续发生的影响，快速切镜本身不保证推进。

每个真实镜头按[画面展开](visual-description.md)的硬性完成条件写成具体画面与声音。当前取景内的主体、行动对象、起态、过程与结果，可见身体配合、接触转移、具体触发与回应、本镜受光和声音都落实到正文。有相关行为而只有动作结果或情绪标签，该镜未完成，先补足同一次演出再进入整理。镜外过程有明确依据，在其结果重新进入画面时能接上。连续声音按实际原文词段落在镜头里，不只写“继续说话”。

保留必要的空间和光源基底。摄影机换位可以改变画面左右、遮挡和照亮的面，人物及固定物的实际位置须由演出承接。选择看背影、侧脸或眼睛时，对应修改能表达的表演细节。

## 保存方式

保存 `整场声画稿.md`，内容包括本场初态、空间与光源基底，随后按真实镜号连续展开，最后写本场实际结果和未完进度。人物名字及真实素材引用、取景范围、摄影机位置与方向、已选运动、具体声画必须能读到；其他排版可按任务调整。此阶段不需要把同一演出反复写成各 Clip 的三条链和状态。

例如一个镜头块可以写成：

```text
镜01｜景别、取景范围与构图｜摄影机位置、朝向、必要高度
运镜：固定观看，或从何处沿什么路径看到何处。
画面与声音：按实际演出连续写主体和对象、动作起点到落点、可见的身体配合与回应、环境接触及本镜受光；同一时间发生的内容连写。发言注明声源、画内/画外及实际原文词段，接触与同步声对应。发生切镜时，说明是哪个话语或动作节点。
```

这只是便于读取的示例，没有规定每镜必须发生几件事或出现多少人。角色外观以项目素材为准；场景与动作中需要的可见信息正常展开。

## 整理阶段如何继承

整理调用接收完整源稿、完整整场稿、制作记录和生产参数。沿用制作记录中的连续发言、动作及并行关系，将已经成立的声画分进Clip并取得对应时长；缺少共用估时依据时先补齐。整场镜号沿用到最终稿；同镜跨 Clip 仍是该镜的连续部分，硬切才产生新镜号。

分镜参考用于前面的整场拍法选择。整理时依据已经完成的演出分段，不把每个Clip重新当作一场套用模板；三条链和边界状态随后从这一次演出提取。

把状态和过程概览从实际镜头提取：如概览声称听者受到触动，应能在镜头的画面或声音中找到对应表现。仅有概览句、没有对应演出时，回到整场设计决定拍法，随后同步整理稿。

初稿可修订。若分组暴露遗漏或速度不成立，保存修订依据与新版整场稿，再更新分组；不能把错误的第一阶段冻结成无法改变的事实。后续两轮复核仍可做同样的修正。

## 实际运行

新场完整流程为：整场设计调用 → 整理调用 → 整体复核一 → 整体复核二。每次保存实际输入、完整输出和修订后的稿件。已有整场稿或用户只委托其中阶段时按实际范围执行。

各阶段共同服务于同一份视频生成执行稿。整理阶段继承已选拍法；必要修订回到整场声画方案并同步相关状态。单次回答可以交候选文本，但不能声称已经完成了四次实际调用。
