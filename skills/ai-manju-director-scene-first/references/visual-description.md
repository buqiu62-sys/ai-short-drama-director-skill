# 画面展开：具体演出的硬性完成条件

整场设计与Clip整理都读取本文件。下列要求是镜头正文的完成条件；选择景别、机位、运镜、切点和演出方案仍由制作师完成。先确定这次演出怎样实际发生，再把当前镜头能看见、能听见的过程写出来。字段齐全、动词按顺序出现或字数增加都不能替代过程。

是否适用按本镜发生的事件与可见范围判断：有持物或交接，就写清接触与归属；有信息接收，就写出触发与当下回应；有动作，就写出当前相位和可见配合。有这些行为而缺少对应正文，该镜未完成，不能以“动作简单”“基本能读懂”改判为不适用。静止或维持态度本身可以是演出，写明当下姿态、注视对象和保持的行为，不凭空增加动作。

本镜中的剧情行动，以及人物和物件的状态变化，都属于须展开的过程，不能只挑最显眼的一个。准备已经在前镜完成时继承实际起态；未发生接触或位移时不生造相应阶段。完整度以本镜实际覆盖的过程为准，而非给每个镜头重复一套固定动作。

## 展开什么

| 维度 | 落到镜头正文的内容 |
|---|---|
| 主体、对象与起态 | 写清画中是谁、相对场景参照的位置、朝向和注视对象，以及进入本镜时正在做什么。动作涉及的手、持物和接触分别归属到人；“他／她／对方”可能混淆时写名字。同框人物各自的行为有归属，镜外人物及物件的相关状态另作承接。 |
| 动作路径与身体配合 | 每个核心动作写出本镜实际覆盖的起态、进行过程及末态；进入新接触、转移或放开时，明确谁先接住或承托、谁再松开、物件最后由谁或什么支撑。写实际参与的主动部位，以及当前画幅可见的支撑、身体配合或动作引起的自然随动。起身要能跟随离开座面到站稳的过程，交物要能跟随持有权转移；不能只列“起身、递给、放入”等动作结果。跨镜尚未完成的动作保留真实相位，不在每镜重演整套过程。 |
| 表情、情绪与对方反应 | 写出具体触发词段、声响或事件，以及接收者先前的可见状态。受到影响时写哪个行为或面部部位怎样变化，随后怎样掩饰或接到下一步；维持态度时写关键话意进行中如何继续原行为、保持注视或不接话，不强制产生情绪变化。注视有明确对象，演出落到当前取景看得见的脸部、身体或听得见的发声。情绪标签只能辅助解释；只写“紧张地看着”“震惊”“压着怒气”而没有具体演出，未满足本项。反应不提前于信息。 |
| 场景层次、接触与环境变化 | 写出本镜成立的主体、对象、前后层次与遮挡参照。动作发生接触时，写接触方式和真实结果：衣料怎样受牵、物件怎样位移或被托稳、接触面怎样响应或保持。已有风雨、烟雾、反光等按来源参与过程；安静或静态环境保持既定状态，不为了填项添加灰尘、风或破坏。纯局部取景不强造四层空间。 |
| 光照与可见表面 | 每镜交代已定主光源的方向、实际照到主体或关键物件的哪个可见面，以及暗面或遮挡怎样形成。存在多光源或反射光时交代其真实作用部位；不为填项创造新光源。转头、遮挡或跨光区时接续受光变化；同场换机位仍依据同一灯窗关系。不能只用“冷光”“电影感”替代本镜受光。 |
| 声音与时间承接 | 标明本镜实际发声者、画内或画外及原文词段，触发反应的位置与连续声音进度相对应。接触产生可听声时与接触同步；既有环境底声按来源持续或因遮挡改变，设计静音则有进入与恢复节点。无新声响时承接已有声场，不凭空添加音效。画面细节与对白、动作共用同一段时间，依[timing.md](timing.md)处理并行关系。 |

## 展开到什么程度

描述随景别分配。全景讲清位置、行进与支撑，中景保住脸、手和关键接触，近景或特写写足取景里的具体变化；镜外姿态和持物进入状态承接，不把镜外身体当作画内可见内容。若本镜要表现关键转移、支撑或反应，但取景容纳不了，就调整取景或在同一次事件中切到能看清的位置，不能用一句概述跨过去。脸部特写不必写看不到的脚部，然而脚部造成的状态变化必须在实际可见镜头或明确镜外过程里成立。

自然反应服务于具体演出：用力时呼吸怎样变化，收手后衣料怎样跟随，听到关键话意时哪个正在进行的动作改变。人物安静时交代当下姿态、注视和可感知状态；背景人物保持各自合理的活动。自然配合要来自当前动作、姿态与人物选择，不把眨眼、握拳、移重心固定分配给所有人。

句数和字数自由，完成条件固定：读正文能够跟随本镜核心动作或反应的实际过程，明确其对象、触发、接触或支撑、当前可见配合及达到的状态。完整的一句话可以使用；一个概括动词不能代替尚未写出的执行关系。固定空间、光源和稳定环境先在Clip基底说明，镜内仍写当前主体的实际受光和演出；连续动作按相位接续，不逐秒复制全身说明。尺寸、角度、色温有实现依据才给出，普通表情用可辨的幅度与方向表达。

动作链、反应链和情绪变化按[输出格式](output-format.md)分别展开行动实现、信息接收及相互影响、态度显露。三链声称发生的核心变化必须在对应镜头正文中有可见或可听过程；镜内只有结果、三链另写了过程，仍属于镜头未完成。复核按[逐镜完成度证据](production-review.md)核验，缺失就回到该镜补齐或修正拍法，不以加长三链代替正文。

所有镜头都考虑场景层次和环境状态，画面成立的层次才进入描述：纯脸部特写不必生造前景物，清洁无风的室内不必增加飘尘，既有静态背景也不必为了数量而运动。环境变化要与已定空间、天气、人物动作或能力相连。连续的呼吸或粒子运动不能单独证明一个长镜头有足够观看内容；持续观看仍须符合整场演出与[对白规则](dialogue.md)。

新增的是可见的实现细节。锁定台词、揭示顺序、人物知情、能力及结果沿用源稿；人物造型由已有素材负责。保持当前画风与语言，不因为展开物理关系自动转成真人、英文或新增伤势与剧情。最终仍只写Clip总时长，关键帧不是本版交付项。

## 两个展开示意

下例只说明如何把过程写实，不规定角色、道具、动作数量或拍法。

**交接：** 甲在桌左、乙在桌右，钥匙起初由甲右手捏住。双人中景取入两人的脸、手及桌面。甲把钥匙递到乙左手前，说“拿好”；乙左指捏住钥匙柄后，甲才松开并收回空手。乙把钥匙带回自己面前，视线从钥匙抬回甲脸上。窗光在钥匙转动时从边缘移到柄面，衣袖轻擦桌沿的声音随收手结束。这些动作与短句同时推进。

**克制的接收：** 乙听甲画外说到“账本在你那里”时，原本沿碗沿移动的拇指停下，眼睛从碗移到甲脸上，下颌略收；甲后半句继续，乙嘴唇仍合着，扶碗的手未离开。中近景保留乙的脸和手，桌角在下方提供接触参照，背景窗框虚化；乙抬脸后沿原窗光多露出受光的面颊，屋外既有雨声持续。不能只把这些概括为“乙紧张”。

这两类展开同样用于同框、反应镜、人物独处与动作戏。先确定当前事件怎样演，再选择其中真实可见的身体、环境和声光关系。

## 同一动作的完成程度对照

**未完成的动作提纲：** “坐在原地，把锦盒从课桌里拿出来，拉开书包拉链，放进去，再拉上拉链。”它列了顺序，却未交代书包的支撑、两手分工、放稳和松手；若取景仅是拉链特写，也容纳不了整段取盒过程。

**具体展开示意：** 锦盒已经被右手取到桌边，书包横放在大腿上，包侧抵住桌沿，包底由双腿承托。取头至大腿上段的画面，容纳上身、两手、桌沿、包口及包底落在腿上的支撑处：左手捏住拉链头拉开，包侧仍抵着桌沿，再撑住包口；右手把闭合锦盒送入，盒底接触包内书本后放平，右指松开，空手退出。包侧布料被撑出方角，衣袖擦过包边轻响；原窗光照到盒盖，顶部白灯保住包口和手指。右手转握拉链头，左手扶包边，拉合后右手留在链头处，左手仍扶住包边。

该例只展示完成程度。人物、道具、左右手、景别和动作数量不是固定模板；实际演出采用本场已定事实与取景。反应镜也依同样标准写出触发前状态、具体触发、可见变化与落点，而不是增加固定数量的动作。
